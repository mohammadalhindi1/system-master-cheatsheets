# Ultimate OS Cheatsheets
A complete collection of Windows & Linux command references, shortcuts, troubleshooting steps, and deep system internals — created by **Mohammad Alhindi **.

This project is designed for:
- Developers and DevOps engineers
- System administrators
- 42 school cadets and IT students
- Anyone who wants a clean and fast system cheatsheet

---

## 📂 Files Included

### 🟦 Windows Master Cheatsheet (PDF)
File: `windows-master-cheatsheet.pdf`

Includes:
- System information & diagnostics (msinfo32, dxdiag, systeminfo…)
- Cleaning & maintenance (temp, %temp%, prefetch, cleanmgr…)
- System repair commands (SFC, DISM, CHKDSK)
- Disk & partition management (DISKPART basics)
- Deep explanation of BIOS vs UEFI vs NVRAM
- UEFI boot repair using `bcdboot`, `mountvol`, `bcdedit`
- Networking commands (ipconfig, netstat, netsh…)
- PowerShell essentials
- Windows keyboard shortcuts
- Security & hardening basics
- Notes about Boot Override and how UEFI actually behaves

---

### 🟩 Linux Master Cheatsheet (PDF)
File: `linux-master-cheatsheet.pdf`

Includes:
- Basic CLI commands (ls, cd, rm, cp, mv, nano, cat…)
- Permissions and ownership (chmod, chown, chgrp)
- System monitoring (top, htop, free, df, du…)
- Services with systemd (systemctl)
- Networking (ip, ping, ss, curl, wget…)
- SSH basics (ssh, scp, ssh-keygen, ssh-copy-id)
- Disks & partitions (lsblk, blkid, fdisk, mount/umount…)
- Linux filesystem structure (`/`, `/home`, `/etc`, `/var`, `/boot`, `/tmp`)
- UEFI + GRUB Linux boot flow
- Terminal shortcuts (Ctrl+C, Ctrl+R, Ctrl+L…)
- Basic security & hardening tips
- Logs and temp paths (`/tmp`, `/var/log`, journalctl)

---

## 🧠 Extra Concepts Covered

This project also helps you understand:

- What is BIOS vs UEFI in simple terms

- How bootloaders work in Linux (GRUB) and Windows

- How SSH and basic Linux networking fit into real DevOps work
